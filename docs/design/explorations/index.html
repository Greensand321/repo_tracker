Bearingdesign explorations
Six full interfaces, all speaking the one design language lifted from the prototype's variant C — rows on a rule, a fixed time column, a glyph gutter, mono for facts and serif italic for reflection, and teal used exactly once. The language lives in base.css and never changes between them; what changes is the structure built on top. Every one renders the same sample Snapshot from data.js and computes nothing of its own.

Use ← → to flip between them.
Nothing here is wired to the engine yet — these are interfaces over a fixed sample snapshot, so every number, branch name and summary you see is plausible rather than live. The point is the structure and the reading, not the data.

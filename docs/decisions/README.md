# Decisions

One file: [`decision-log.md`](decision-log.md).

It holds every locked decision with the reason behind it and the document it came from,
plus the questions still open. Check it before reopening an argument — several of these
were settled twice already.

Overturned decisions stay in the table, struck through, with the replacement noted. The
trail is the point: a decision without its reasoning cannot be re-evaluated later, only
re-argued.

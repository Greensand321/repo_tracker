# Decisions

| File | What it is |
|---|---|
| [`decision-log.md`](decision-log.md) | Every locked decision, with the reason behind it and the document it came from. Check it before reopening an argument — several of these were settled twice already. |
| [`open-questions.md`](open-questions.md) | Questions that need the owner's answer before they can become decisions. Each states why it matters and what ships by default if it goes unanswered. **Q1–Q5 are blocking.** |

Answers land inline in `open-questions.md`; anything that settles a design choice
graduates to a row in the decision log.

Overturned decisions stay in the table, struck through, with the replacement noted. The
trail is the point: a decision without its reasoning cannot be re-evaluated later, only
re-argued.

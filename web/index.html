It only proposes when it can be specific — a purpose nothing could contradict is worthless as a yardstick, so it says nothing rather than padding. Proposals are always marked until you confirm them.
When it judges a branch against what the branch is for, it can read the branches next to it and how things moved this week — instead of inferring both from commit messages. It costs a call or two more per branch, and it is what turns “drifted” and “already done elsewhere” from a hunch into a finding. Switching this regenerates those judgements, because they were drawn from different evidence.
